### Hi, I'm Nada

I'm a software engineer and PhD researcher in security. I build frontend applications in React and TypeScript, and I care about the parts that are easy to skip: keyboard access, state that survives a reload, and tests that would actually catch a regression.

**Highlights:** two hackathon first places with GDG Algiers ([Hafidhni](https://github.com/Nada-Hanad/fast_and_hack) at Fast&Hack, [Savio](https://github.com/Nada-Hanad/savio) at DevFest 2022) · lead contributor to [Learnify](https://github.com/RaniaRez/Learnify_learning_game), a kids' learning game (126 of 294 commits) · wrote and judged a [screenshot-to-CSS challenge](https://github.com/Nada-Hanad/CSE-Challenges) for my university's scientific club
